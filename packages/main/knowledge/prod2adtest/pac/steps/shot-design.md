# 画面设计规格

你交的是**规格**,不是图。真正出图由 delivery 统一做,这里不要试图自己渲染。

上游的 `visual_style_token` 直接决定取景与光影,不要另起一套风格。

## 输入契约

- 核心卖点:`{{inputs.core_selling_point}}`
- slogan:`{{inputs.slogan}}`
- 视觉风格令牌:`{{inputs.visual_style_token}}`
- 色彩情绪:`{{inputs.color_emotion}}`
- 渠道类型:`{{inputs.channel_type}}`

## 工作流程

### 1. 元素选择

**设计主要元素(结合主要信息或客户所提供图片进行创造或提取)**

规则:

- 主体 + 材质 + 环境 + 光影 + 镜头 + 风格 + 负面提示词。

**设计辅助元素(起到辅助说明作用)**

规则:

- 同一系列产品,主客体描述必须完全一致,仅改变构图或场景。

**设计辅助图形(起到辅助引导作用)**

规则:

- 不可以出现负面词表中的问题。可以分情况叠加不同分类的负面词方便准确定位。

### 2. 版式设计

**确定核心信息和元素主体位置**

规则:

- 电商主图:产品占比≥60%,文字不超过画面20%。
- 详情页:遵循"F型"或"Z型"阅读动线。
- 产品图必须成为视觉中心。

**确定辅助信息和辅助元素位置**

规则:

- 同一系列产品,主客体描述必须完全一致,仅改变构图或场景。
- 在详情图中可以出现产品特写,增强观感。

**确定辅助图形位置**

规则:

- 同一系列产品,主客体描述必须完全一致,仅改变构图或场景。

**利用版式和大小营造空间感**

### 3. 画面材质与质感

**根据主要元素调整画面整体质感**

规则:

- 光影描述需具体。
- 根据产品材质调整光影(例如:金属高光、纸张柔光)。

**根据某些特定元素赋予独特材料质感**

**调整整体版式和元素,根据不同材料呈现对应观感**

### 4. 拼装完整中文提示词

把主体、材质、构图、环境、光影、镜头、风格组合成一段完整的中文提示词,可直接投喂国内图像生成软件。
